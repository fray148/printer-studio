# Printer Studio

**Версия 1.5.1** · [История изменений](CHANGELOG.md)

Панель для FlashForge Creator 5 Pro. Этот выпуск синхронизирован с работающей
версией на debserver: мониторинг, материалы, камера, таймлапсы, Telegram,
журнал событий и управление текущей печатью.

## Возможности

- Статус печати, прогресс, температуры, активный инструмент и расход материалов.
- **Пауза, продолжение и отмена печати** с подтверждением действия.
  Перед командой проверяются состояние принтера и имя текущего файла;
  после отправки панель проверяет изменение состояния.
- Управление светом, просмотр камеры и закрытие диалога завершённой печати.
- Учёт материалов по типу и цвету, статистика катушек и история печати.
- Ручные и автоматические таймлапсы, MP4, архив JPEG, просмотр и скачивание.
- Telegram: статус, фото, таймлапсы и уведомления о ходе печати.
- Журнал событий с фильтрами, пагинацией, событиями связи и смены инструмента.
- Исправлена обработка служебных операций с филаментом: они не считаются
  новой печатью и не запускают автоматическую запись.

## Подключение и ZMOD

Этот выпуск использует **штатный HTTP API FlashForge** на порту 8898
и требует серийный номер и код доступа. Если на принтере установлен ZMOD,
для этой панели должен оставаться доступен совместимый штатный API.
Прямой backend Moonraker из отдельной версии 1.5.0 здесь не используется.
Совместимость всех функций с другими конфигурациями ZMOD отдельно не проверена.

## Установка

```sh
git clone https://github.com/fray148/printer-studio.git
cd printer-studio
cp .env.example .env
# Укажи в .env адрес принтера, серийный номер и код доступа.
docker compose up -d --build
```

Открой http://localhost:5012/. Порт 5012 должен быть доступен только доверенным
пользователям; для доступа извне настрой авторизацию на обратном прокси.
Настройки, история, материалы и записи сохраняются в `./data`.
`.env` и `data/` исключены из Git и Docker-контекста.

Для обновления существующей установки сохрани её `.env`, каталог `data`
и настройки портов/сетей Compose. Затем пересобери контейнер.

## Проверки

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -q
```

Для проверки сборки MP4 нужен FFmpeg. Дополнительные сведения: [FORK.md](FORK.md).

# Printer Studio ZMOD

**Версия 1.5.0** · [История изменений](CHANGELOG.md)

Самостоятельный форк [Creator 5 Pro Dashboard](https://github.com/afeind/Creator-5-Pro-Dashboard)
для FlashForge Creator 5 Pro с ZMOD. Сохраняет оформление, мониторинг,
учёт материалов, историю, камеру, таймлапсы, архив и Telegram прежней панели.
Основной источник данных — Moonraker; штатный HTTP API доступен как
дополнительный источник данных FlashForge.

## Возможности

- Статус печати, температуры, материалы и камера в стиле исходной панели.
- Ручная или автоматическая запись кадров с одной общей камеры.
- Сборка MP4, просмотр, скачивание видео и ZIP с исходными кадрами.
- Переименование и удаление записей в веб-интерфейсе.
- Telegram: статус, фото, готовое видео и уведомления о печати.
- Отдельный Docker Compose-проект на порту 5013 со своим каталогом данных.

## Запуск

Создай файл `.env` и укажи адрес, серийный номер и код доступа принтера:

```sh
cp .env.example .env
$EDITOR .env
docker compose up -d --build
```

Открой [панель](http://localhost:5013/). Данные сохраняются в каталоге `data`.
Файл `.env` и каталог `data` исключены из Git и Docker-образа.

## ZMOD

Для ZMOD в `.env` выбери другой источник данных:

```ini
PRINTER_BACKEND=zmod
PRINTER_HOST=192.168.1.98
MOONRAKER_URL=http://192.168.1.98:7125
# MOONRAKER_API_KEY=твой_ключ
```

Укажи свой адрес и доступный из контейнера URL Moonraker. При доступе через
обратный прокси URL может использовать порт 80. Серийный номер и код
FlashForge необязательны: если указать их, штатный API дополнит данные
материалов, общих счётчиков, TVOC, диска и версии прошивки. Недоступность
штатного API не останавливает мониторинг Moonraker. Ключ Moonraker хранится только
в `.env`, запросы выполняет сервер панели.

После изменения настроек выполни `docker compose up -d --build`.
Статус, прогресс, температуры нескольких сопел, стол, скорость, расход
филамента и миниатюры берутся из Moonraker. Расход переводится из миллиметров
в метры; оставшееся время оценивается по прогрессу. Пауза сохраняет текущую
печать в истории и текущую запись таймлапса.

Камера использует `PRINTER_CAM_PORT` и `PRINTER_CAM_PATH`, как в штатном
режиме. Сначала настрой её в ZMOD: для Creator 5 Pro документация указывает
`CAMERA_ON VIDEO=video67`. Панель подключается к готовому MJPEG-потоку,
не переключая камеру принтера. Запись и Telegram используют тот же поток.

Свет управляется макросами `LED_ON` / `LED_OFF`. Для подтверждения состояния
задай `ZMOD_LIGHT_OBJECT` с именем своего Klipper-объекта, например
`led chamber_led`. Без доступного объекта панель подтверждает только отправку
макроса. Кнопка закрытия диалога отправляет
`FAST_CLOSE_DIALOGS` только после завершения печати. Состояние `completed`
в Moonraker может сохраняться после закрытия окна на экране.

Слоты материалов читаются из `zmod_color`, если установленная версия ZMOD
публикует их в Moonraker, либо из штатного API при указанных реквизитах.
Если оба источника недоступны, слоты не выдумываются; тип пластика для учёта
расхода определяется из имени файла. Полное соответствие показаний прежней
панели требует проверки этих источников на принтере.

Из управления принтером оставлены только свет и закрытие диалога.
Команд движения, нагрева, запуска, паузы и отмены печати в панели нет.
Кнопка камеры управляет просмотром в панели и не переключает камеру ZMOD.

Документация: [особенности Creator 5 Pro](https://wiki.zmod.link/C5PRO/),
[макросы ZMOD](https://wiki.zmod.link/Main/),
[API Moonraker](https://moonraker.readthedocs.io/en/latest/external_api/printer/).

## Telegram

Создай бота через `@BotFather`, открой чат своего бота и нажми **Start**.
Токен и числовой `chat_id` введи на [вкладке «Бот»](http://localhost:5013/bot).
Бот выключен, пока ты сам его не настроишь и не включишь.

## Документация и проверки

Параметры хранения, ресурсы контейнера и инструкции по управлению:
[FORK.md](FORK.md). Для запуска тестов нужны Python-зависимости из
`requirements.txt` и FFmpeg.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -q
```
